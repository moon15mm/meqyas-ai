# «لا تخلّي الكرتون المطعوج يفضحك في إكس!» — Meqyas Commerce AI × QEU

إعلان ريلز فيروسي مدته **35 ثانية** بمقاس الجوال **9:16 (1080×1920 · 30fps)**، مبني كمكوّن React تفاعلي
(React + Tailwind CSS + Lucide + Framer Motion) ويُصدَّر إلى **MP4 حقيقي** بالكود نفسه عبر Remotion.

|                                   |                                                                                          |
| --------------------------------- | ---------------------------------------------------------------------------------------- |
| **المشغّل التفاعلي**              | `pnpm start` ← http://127.0.0.1:3151 (نسخة الإنتاج، الأسلس) · `pnpm dev` ← :3150 للتطوير |
| **ملف HTML واحد يعمل دون إنترنت** | `pnpm build` ← `dist/index.html` (الخطوط والصوت والكود مضمّنة، ≈1.2 MB)                  |
| **فيديو MP4**                     | `pnpm render` ← `out/meqyas-qeu-reel.mp4` (H.264 + صوت AAC)                              |

> الحزمة مستقلة عن مساحة عمل pnpm للمنتج (لا تلمس `pnpm-lock.yaml` في الجذر)، لذا تُثبَّت بـ:
>
> ```bash
> cd marketing/qeu-reel
> pnpm install --ignore-workspace
> ```

## 1. المشغّل

- **تشغيل / إيقاف / إعادة** وشريط زمني من 0 إلى 35 ثانية **يتجه من اليمين إلى اليسار** (D-033)، عليه ألوان المشاهد
  الستة وعلامات المؤثرات الصوتية؛ اسحب للتنقل بدقة الإطار.
- **الاختصارات:** `Space`/`K` تشغيل · `←` تقديم ثانية · `→` ترجيع ثانية · `.` / `,` إطار · `Home`/`End` · `R` إعادة ·
  `M` كتم · `C` واجهة المنصة · `F` ملء الشاشة.
- **مفاتيح العرض:** الترجمة (كاريوكي) · مؤشرات الصوت (SFX) · واجهة المنصة (ريلز/تيك توك معكوسة للعربية) · تكرار · السرعة.
- **الصوت** مُولَّد بالكامل برمجيًا في Web Worker (لا ملفات صوتية ولا موسيقى مرخّصة)، ويتبع الصورة: إذا تأخر جهاز الصوت
  في البدء أو انحرف يُعاد ضبطه تلقائيًا.
- **روابط مراجعة** (بلا واجهة): `?view=stage&t=12.5` إطار واحد · `?view=stage&t=12.5&focus=0,700,1080,600` جزء مكبّر ·
  `?view=sheet&from=0&to=35&step=1.5` لوحة إطارات · `?t=20` يفتح المشغّل عند ثانية معيّنة.

## 3. البنية

```
src/reel/timeline.js     مصدر الحقيقة الوحيد: المشاهد، اللحظات، النصوص، الترجمة، المؤثرات
src/reel/anim.js         أدوات حركة حتمية (interp · spring · noise · shake) — كل قيمة دالة في الزمن
src/reel/soundtrack.js   توليف الصوت والموسيقى رياضيًا (يعمل في المتصفح وNode)
src/reel/ReelStage.jsx   المسرح 1080×1920 = دالة نقية في t
src/reel/scenes/*        Hook · Phone (إكس/واتساب/الإصبع) · FreezeHud (الرادار) · Outro
src/reel/parts/*         الشعارات، سعود (SVG بالشماغ والعقال)، الكاميرا الأمامية والعدّاد، الترجمة، المؤثرات
src/MeqyasQeuReel.jsx    المشغّل التفاعلي (Framer Motion للواجهة فقط)
remotion/                تكوين Remotion الذي يرسم ReelStage إطارًا بإطار
scripts/render-audio.mjs يكتب public/qeu-reel-audio.wav للتصدير
```

**لماذا كل شيء دالة في الزمن؟** لأن الحركات الزمنية (CSS/Framer Motion) لا يمكن سحبها إلى إطار بعينه ولا تُرسم بثبات في
تصدير الفيديو. هنا أي إطار يُرسم وحده بالضبط: في المشغّل عند السحب، وفي Remotion عند التصدير. Framer Motion مستخدمة لواجهة
المشغّل (الأزرار، تبديل المشاهد، الألواح).

**لتعديل الإعلان:** النصوص والتوقيتات ومواضع الملصقات كلها في `timeline.js`؛ الصوت يتبع اللحظات نفسها تلقائيًا.

## 4. التصدير إلى MP4 (Remotion)

```bash
pnpm render                       # يولّد الصوت ثم يرسم 1050 إطارًا → out/meqyas-qeu-reel.mp4
pnpm studio                       # Remotion Studio للمعاينة والتعديل
pnpm still                        # إطار واحد (330) → out/frame.png
```

- أول تشغيل ينزّل Chrome Headless Shell (~100 MB) مرة واحدة. لاستخدام نسخة مثبتة: `REMOTION_BROWSER_EXECUTABLE=…`.
- واجهة المنصة لا تُصدَّر (المنصة تضيف واجهتها). لإخفاء الترجمة أو المؤثرات المطبوعة:
  `npx remotion render remotion/index.jsx QeuReel out/clean.mp4 --props='{"showSubtitles":false,"showSfx":false}'`
- الملف الناتج H.264 (`yuv420p` · bt709 · CRF 20) بنحو 15 ميغابت/ث. حبيبات الفيلم في التصدير **ثابتة** (`grain: "static"`):
  الحبيبات المتحركة كل إطار ترفع الحجم نحو 5 أضعاف وتتشوّه بإعادة ضغط المنصات. للمظهر المتحرك: `--props='{"grain":"animated"}'`،
  ولإلغائها: `"off"`.
- لإضافة تعليق صوتي حقيقي أو موسيقى: ضع الملف في `public/` وأضف `<Html5Audio src={staticFile("…")} />` في
  `remotion/QeuReel.jsx`.
- **ترخيص Remotion:** مجاني للأفراد والشركات حتى 3 موظفين؛ ما فوق ذلك يحتاج ترخيص شركة (remotion.pro). البديل المجاني:
  تسجيل إطارات `?view=stage` بأي متصفح آلي وتجميعها بـ ffmpeg.
- اختير Remotion بدل MoviePy لأنه يرسم مكوّنات React نفسها؛ MoviePy كان يتطلب إعادة كتابة كل مشهد في بايثون.

## 5. صدق الرسالة

- الإعلان **مشهد تمثيلي** (مكتوب في الخاتمة). الرادار يقرأ إشارات تملكها المنصة فعلًا: تقييم «نبض» بعد التوصيل، بيانات
  الطلب من ربط المتجر، و**حالة متابعة** تُفتح تلقائيًا لكل تقييم منخفض (CX.md §5). المنصة لا تقرأ مسودات إكس؛ «300ms
  قبل النشر» مفارقة درامية: الاستجابة أسرع من إصبع العميل.
- التعويض قرار المتجر وسياسته («التعويض يحدده المتجر وفق سياسته» في الخاتمة). إرسال الرسائل عبر واتساب مذكور في خطة
  CX.md §9 كخطوة لاحقة عبر مزوّد مدفوع — راجعوا التوقيت قبل النشر العام.
- كِيو (QEU) علامة تجارية للإعلان؛ واجهات إكس وواتساب محاكاة مبسطة، والشعار الأخضر رمز عام للمحادثة لا شعار واتساب. شعار
  إكس يظهر داخل محاكاة الواجهة: راجعوا إرشادات العلامات التجارية للمنصات قبل تشغيله إعلانًا ممولًا.

## 6. الأداء

صُمّم ليعمل بسلاسة حتى على معالج رسوميات مدمج قديم (Intel HD 4400): كل ما يتحرك في كل إطار يتحرك بـ `transform`/`opacity`
على طبقة مستقلة، لا مرشحات SVG ولا blend modes على عناصر متحركة، الحدود النصية بظلال صلبة بدل `text-stroke`، والمشغّل
يعيد الرسم بمعدل الفيديو نفسه (30 إطارًا) وتُحضَّر المعالجة الرسومية قبل أول تشغيل. نسخة `pnpm build` أسرع بكثير من
`pnpm dev` (وضع التطوير في React 19 أبطأ عمدًا).
